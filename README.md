# Пепельная корона

Игра-платформер на чистом JavaScript и Canvas. Практическое задание 3 курса «Web-дизайн».

Король пал, корона обратилась в пепел, земли прокляты. Охотник идёт к трону
через проклятый лес.

## Что есть сейчас (этапы 1–4)

- Движение, прыжок переменной высоты, гравитация, столкновения с землёй и платформами.
- Три класса на выбор:
  - **Мечник** — удар вблизи, рывок сквозь врагов, больше всего здоровья.
  - **Лучник** — стрелы по дуге, пробивающий выстрел, двойной прыжок.
  - **Маг** — магические шары за ману, взрыв по площади, меньше всего здоровья.
- Три локации с растущей сложностью, у каждой свои враги, ловушки и босс:
  - **Проклятый лес** — слизни и волки, ямы и шипы; босс **Древо-страж** бьёт корнями и призывает слизней.
  - **Разрушенный замок** — скелеты-мечники и скелеты-лучники; босс **Чёрный рыцарь** делает рывок и прыжок с ударной волной.
  - **Пылающее подземелье** — бесы, лава, огненные столбы; босс **Демон** бьёт залпами огня и столбами пламени.
- Опасные атаки видны заранее: метка на полу перед ловушкой, мигание врага перед ударом.
- Боссы спят, пока герой не войдёт на арену; портал открывается после победы над боссом.
- Костёр — контрольная точка и один раз за забег полностью лечит.
- Короткие сюжетные тексты перед локациями и финал после третьего босса.
- С убитых врагов выпадает золото.
- Снаряжение четырёх редкостей (обычное, редкое, эпическое, легендарное) в три слота:
  оружие, броня, амулет. Падает с врагов с шансом 15 %, даёт урон, здоровье,
  скорость атаки и шанс критического удара.
- Сумка на 12 предметов, экран снаряжения со сравнением, разбор лишнего в золото.
- Карта локаций. Прогресс сохраняется в браузере (`localStorage`) и переживает перезагрузку.
- Сбор золота — счёт. Здоровье, поражение, прохождение уровня.
- Меню, выбор класса, пауза, рестарт. Автопауза при переключении вкладки.
- Золото забега прибавляется к общему при прохождении уровня и теряется при гибели;
  найденные предметы остаются в любом случае.

## Управление

| Действие | Клавиши |
|---|---|
| Влево / вправо | A / D, ← / → |
| Прыжок | Пробел, W, ↑ |
| Атака (можно удерживать) | J |
| Способность класса | K |
| Пауза | P, Esc |

Управление не зависит от раскладки клавиатуры.

## Запуск

Игра использует ES-модули, поэтому нужен локальный сервер:

```bash
python3 -m http.server 8000
```

Затем открыть http://localhost:8000.

## Тесты

Нужен Node.js 20 или новее. Зависимостей нет.

```bash
node --test
```

## Устройство

- `js/Game.js` — игровой цикл с фиксированным шагом 1/60 с, состояния, правила мира.
- `js/Collision.js` — столкновения прямоугольников и тайлов.
- `js/entities/` — герой, враги, боссы, снаряды, добыча.
- `js/systems/` — генерация лута, инвентарь, сохранение.
- `js/data/classes.js`, `js/data/enemies.js`, `js/data/items.js` — числа классов, врагов и предметов.
- `js/Level.js`, `js/data/levels.js`, `js/data/story.js` — разбор и описание локаций, сюжетные тексты.
- `js/Renderer.js`, `js/ui/` — отрисовка и экраны.
- `js/data/sprites.js` — пиксельная графика, описанная в коде.

## Ресурсы и лицензии

Вся графика создана кодом проекта. Сторонние изображения, звуки и библиотеки не используются.
