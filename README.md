# Пепельная корона

Игра-платформер на чистом JavaScript и Canvas. Практическое задание 3 курса «Web-дизайн».

Король пал, корона обратилась в пепел, земли прокляты. Охотник идёт к трону
через проклятый лес.

## Что есть сейчас (этап 1)

- Движение, прыжок переменной высоты, гравитация, столкновения с землёй и платформами.
- Уровень «Проклятый лес»: ямы, шипы, платформы, два костра-контрольные точки, портал.
- Сбор золота — счёт. Здоровье, поражение, прохождение уровня.
- Меню, пауза, рестарт. Автопауза при переключении вкладки.

## Управление

| Действие | Клавиши |
|---|---|
| Влево / вправо | A / D, ← / → |
| Прыжок | Пробел, W, ↑ |
| Пауза | P, Esc |

Управление не зависит от раскладки клавиатуры.

## Запуск

Игра использует ES-модули, поэтому нужен локальный сервер:

```bash
python3 -m http.server 8000
```

Затем открыть http://localhost:8000.

## Тесты

Нужен Node.js 20 или новее. Зависимостей нет.

```bash
node --test
```

## Устройство

- `js/Game.js` — игровой цикл с фиксированным шагом 1/60 с, состояния, правила мира.
- `js/Collision.js` — столкновения прямоугольников и тайлов.
- `js/entities/` — герой.
- `js/Level.js`, `js/data/levels.js` — разбор и описание уровня.
- `js/Renderer.js`, `js/ui/` — отрисовка и экраны.
- `js/data/sprites.js` — пиксельная графика, описанная в коде.

## Ресурсы и лицензии

Вся графика создана кодом проекта. Сторонние изображения, звуки и библиотеки не используются.
