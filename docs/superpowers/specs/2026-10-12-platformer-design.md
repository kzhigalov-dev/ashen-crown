# «Пепельная корона» — спецификация игры-платформера

Дата: 2026-10-12
Задание: практическое задание 3 курса «Web-дизайн» — «Игра-платформер на JavaScript».
Название рабочее.

## 1. Цель

Платформер с видом сбоку в мире тёмного фэнтези. Идея вдохновлена Path of Kings
(охота на чудовищ, выбивание снаряжения, рост силы героя), но жанр, графика,
название и код — собственные. Ничего из оригинала не заимствуется.

Игра должна закрывать все обязательные пункты задания, блок «Проверка качества 2026»
и большую часть списка «для повышения оценки».

## 3. Технологии

- HTML, CSS, JavaScript (ES-модули), Canvas 2D API, Web Audio API.
- Без сборки, без сторонних библиотек.
- `package.json` без зависимостей, только `"type": "module"` и скрипт тестов —
  нужен, чтобы `node --test` читал те же модули, что и браузер.
- ES-модули не работают по `file://`: локальный запуск через любой статический
  сервер (`python3 -m http.server`).
- Публикация: GitHub Pages из корня ветки `main`.

## 4. Управление

| Действие | Клавиши |
|---|---|
| Влево / вправо | A / D, стрелки ← → |
| Прыжок | Space, W, стрелка ↑ |
| Атака | J |
| Способность | K |
| Пауза | P, Esc |

Всё управление доступно с клавиатуры, мышь не обязательна. Подсказка по клавишам
показывается на экране выбора класса и в меню паузы. Сенсорное управление и
геймпад не поддерживаются.

## 5. Цикл, физика, коллизии

**Экран.** Canvas с логическим разрешением 480×270. Масштабируется целым множителем
под окно, сглаживание выключено. Тайл — 16×16 пикселей.

**Игровой цикл.** `requestAnimationFrame`. Реальное время кадра накапливается и
расходуется фиксированными шагами по 1/60 с; отрисовка — один раз за кадр. Время
кадра ограничено сверху 0,1 с.

```js
function frame(now) {
    accumulator += Math.min((now - last) / 1000, 0.1);
    last = now;
    while (accumulator >= STEP) {
        update(STEP);
        accumulator -= STEP;
    }
    render();
    rafId = requestAnimationFrame(frame);
}
```

**Движение героя.**

| Параметр | Значение |
|---|---|
| Гравитация | 900 px/с² |
| Скорость бега | 110 px/с |
| Начальная скорость прыжка | 300 px/с вверх |
| Предел скорости падения | 400 px/с |

Прыжок регулируется: отпустил клавишу раньше — прыжок ниже. «Время койота» 0,1 с
(можно прыгнуть сразу после схода с края) и буфер прыжка 0,1 с (нажатие чуть до
приземления засчитывается).

**Коллизии.** Все объекты — прямоугольники (AABB). Столкновение с тайлами
разрешается по осям раздельно: сначала сдвиг по X и выталкивание, затем по Y.
Тайлы: пустой, сплошной, односторонняя платформа (можно запрыгнуть снизу),
опасный (шипы, лава). Столкновения объектов между собой — проверка пересечения AABB.

**Камера.** Следует за героем по горизонтали с плавным догоном, ограничена
краями уровня. Фон — 2–3 слоя параллакса.

## 6. Классы

Класс выбирается при начале новой игры и фиксирован. Слот сохранения один;
смена класса = новая игра (с подтверждением сброса).

| | Мечник | Лучник | Маг |
|---|---|---|---|
| Здоровье | 120 | 90 | 70 |
| Атака (J) | удар дугой перед собой, урон 14 | стрела, урон 10, летит по дуге под действием гравитации | шар по прямой, урон 16, стоит 12 маны |
| Перезарядка атаки | 0,4 с | 0,5 с | 0,45 с |
| Способность (K) | рывок вперёд с уроном, 4 с | заряженный выстрел насквозь, 5 с | взрыв по площади вокруг себя, 30 маны, 6 с |
| Особенность | больше всего здоровья | двойной прыжок | мана 100, восстановление 8 в секунду |

Числа — стартовые, балансируются при тестировании.

## 7. Лут и снаряжение

**Слоты:** оружие, броня, амулет. Оружие выпадает только для класса героя
(меч, лук или посох), чтобы не было бесполезных находок.

**Редкость:**

| Редкость | Множитель характеристик | Случайных свойств |
|---|---|---|
| Обычное | ×1,0 | 0 |
| Редкое | ×1,3 | 1 |
| Эпическое | ×1,7 | 2 |
| Легендарное | ×2,2 | 3 |

Базовая характеристика: урон у оружия, здоровье у брони, у амулета — одно из
случайных свойств с повышенным значением. Случайные свойства: урон, здоровье,
скорость атаки, шанс критического удара. Базовые значения растут с номером локации.

**Выпадение.**
- С любого врага — золото.
- С обычного врага — предмет с шансом 15 %.
- С босса — предмет гарантированно, редкость не ниже редкой.
- Веса редкости зависят от локации:

| Локация | Обычное | Редкое | Эпическое | Легендарное |
|---|---|---|---|---|
| Лес | 70 | 25 | 5 | 0 |
| Замок | 50 | 35 | 13 | 2 |
| Подземелье | 30 | 40 | 22 | 8 |

Генератор лута получает источник случайных чисел параметром — в тестах
подставляется детерминированный.

**Инвентарь.** 12 ячеек. Предмет подбирается касанием. Если места нет — предмет
сразу разбирается в золото. Экран снаряжения открывается с карты: надеть, снять,
разобрать. Сравнение с надетым предметом показывается при выборе.

**Золото и счёт.** Золото — это счёт. В HUD показано золото текущего забега.
При завершении уровня оно добавляется к общему; при смерти — теряется.
Найденные предметы остаются в любом случае. В сохранении хранятся общее золото
и рекорд золота за один пройденный уровень. Магазина нет.

## 8. Локации и ход игры

Уровни собраны вручную и описаны массивами строк: символ = тайл или точка
появления объекта. Высота уровня — 17 тайлов, длина — около 200.

| № | Локация | Враги | Опасности | Босс |
|---|---|---|---|---|
| 1 | Проклятый лес | слизень, волк | ямы | Древо-страж |
| 2 | Разрушенный замок | скелет-мечник, скелет-лучник | ямы, шипы | Чёрный рыцарь |
| 3 | Пылающее подземелье | бес, скелет-мечник | лава, огненные столбы | Демон |

**Ход уровня.** Старт → путь по платформам с врагами → 2 костра-контрольные точки →
арена босса → после победы открывается портал → уровень пройден.

- Падение в яму, на шипы или в лаву: потеря 20 здоровья и возврат к последнему костру.
- Огненный столб включается и выключается по таймеру; касание наносит урон
  как удар врага, без возврата к костру.
- Здоровье 0: экран поражения, возврат на карту.
- Победа над боссом локации открывает следующую. Пройденные локации остаются
  доступными для повторного прохождения.
- Победа над Демоном — финальный текст и экран победы. Игру можно продолжать.

**Состояния игры:**

```
меню → выбор класса → сюжетный текст → карта ⇄ снаряжение
карта → игра ⇄ пауза
игра → уровень пройден → карта
игра → поражение → карта
игра (локация 3) → победа → карта
```

**Сюжет.** Король пал, корона обратилась в пепел, земли прокляты. Охотник идёт
к трону через лес, замок и подземелье. Короткий текст (3–4 предложения) перед
каждой локацией и в финале. Тексты лежат в `data/story.js`.

## 9. Враги

| Враг | Поведение |
|---|---|
| Слизень | ходит по платформе туда-обратно, урон касанием |
| Волк | патрулирует; увидев героя, разгоняется в его сторону |
| Скелет-мечник | патрулирует; вблизи замахивается и бьёт с задержкой |
| Скелет-лучник | стоит на месте, стреляет в сторону героя раз в 2 с |
| Бес | летает по синусоиде, стреляет огненным шаром |

Враги не падают с платформ (разворачиваются у края). После получения урона
герой неуязвим 0,8 с и мигает.

**Боссы** — у каждого полоска здоровья и две фазы (вторая после 50 % здоровья:
атаки чаще).
- Древо-страж: стоит на месте, бьёт корнями из-под земли в точке под героем,
  призывает слизней.
- Чёрный рыцарь: рывок через арену, удар по площади при приземлении прыжка.
- Демон: летает, залп огненных шаров веером, огненные столбы на полу арены.

Параметры врагов и боссов — в `data/enemies.js`.

## 10. Интерфейс

- **HUD (Canvas):** здоровье, мана (у мага), перезарядка способности, золото
  забега, полоска здоровья босса.
- **Экраны (HTML поверх Canvas):** главное меню («Продолжить», «Новая игра»),
  выбор класса, сюжетный текст, карта локаций, снаряжение, пауза
  («Продолжить», «Рестарт уровня», «На карту», громкость), поражение, победа.
- Кнопки — настоящие `<button>`, работают с Tab и Enter, видимый фокус.
- Кнопка паузы видна на экране во время игры.

## 11. Сохранение

Ключ `localStorage`: `ashen-crown-save`. Формат:

```js
{
    version: 1,
    classId: 'swordsman' | 'archer' | 'mage',
    equipped: { weapon, armor, amulet },   // предмет или null
    inventory: [],                          // до 12 предметов
    unlocked: 1,                            // сколько локаций открыто
    gold: 0,                                // общее золото
    bestRun: 0,                             // рекорд золота за один уровень
    volume: 0.5,
}
```

Сохраняется при завершении уровня, при смерти, при изменении снаряжения и
громкости. При чтении данные проверяются; отсутствующие, повреждённые или
с другой версией — заменяются начальными. Если `localStorage` недоступен,
игра работает без сохранения и показывает об этом уведомление в меню.

## 12. Графика

Вся графика создаётся кодом. Спрайты описаны в `data/sprites.js` как массивы
строк (символ → цвет из палитры) и при запуске один раз рисуются во внеэкранные
Canvas. Анимации: у героя — стойка, бег, прыжок, атака; у врагов — движение.
Эффекты: числа урона, вспышка при попадании, частицы при смерти врага и
подборе предмета. Цвет подсветки предмета соответствует редкости.

## 13. Звук

Синтез через Web Audio API, звуковых файлов нет. Эффекты: прыжок, атака,
попадание, получение урона, подбор предмета, завершение уровня, поражение.
`AudioContext` создаётся после первого нажатия пользователя. Громкость —
ползунок в меню паузы и главном меню, значение 0 выключает звук.
Фоновой музыки нет.

## 14. Проверка качества 2026

| Требование | Решение |
|---|---|
| Логика по времени кадра | фиксированный шаг с накоплением, раздел 5 |
| Пауза при потере видимости | `visibilitychange` переводит игру в паузу |
| Очистка при перезапуске | `InputHandler.detach()` снимает обработчики, `cancelAnimationFrame` останавливает цикл; `setInterval` и `setTimeout` в игровой логике не используются — все таймеры считаются в `update` |
| Клавиатура и подсказка | раздел 4 |
| Звук после действия, громкость | раздел 13 |
| Лицензии ресурсов | графика и звук созданы кодом проекта, заимствований нет |
| README: браузеры, ограничения, проверка | раздел 16 |

## 16. Проверка и сдача

**Автотесты** (`node --test`, без зависимостей):
- коллизии: пересечение AABB, приземление на тайл, упор в стену, односторонняя платформа;
- лут: распределение редкости по весам, число свойств по редкости, оружие только своего класса;
- инвентарь: предел 12 ячеек, надеть/снять, разбор в золото, итоговые характеристики;
- сохранение: запись и чтение, повреждённые данные, другая версия, недоступное хранилище.

**Ручной сценарий** (результат фиксируется в README): новая игра → выбор класса →
прохождение леса → босс → подбор предмета → экипировка → перезагрузка страницы →
прогресс на месте → пауза при переключении вкладки → рестарт уровня.

**Браузеры:** Chrome, Firefox, Safari актуальных версий, настольные.

**README.md:** описание и функционал, управление, запуск, скриншоты или GIF,
поддерживаемые браузеры, известные ограничения, результаты проверки, лицензии
ресурсов, журнал применения AI-помощника (задача, существенный запрос, принятое
и отклонённое предложение, способ проверки). Раздел «Собственные исправления»
заполняет автор работы своими реальными правками.

**Сдача:** репозиторий на GitHub и ссылка на игру на GitHub Pages.

## 17. Порядок сборки

После каждого этапа игра запускается и пригодна к сдаче.

1. Ядро: цикл, ввод, герой, гравитация, коллизии, один уровень, золото-счёт,
   старт / пауза / рестарт. Обязательные пункты задания закрыты.
2. Враги, бой, три класса, выбор класса.
3. Лут, редкость, инвентарь, экран снаряжения, сохранение.
4. Три локации, боссы, карта, сюжетные тексты, победа.
5. Звук, эффекты, README, публикация.

процедурная генерация уровней, несколько слотов сохранения, смена класса
без новой игры.
