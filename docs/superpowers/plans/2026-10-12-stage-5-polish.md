# «Пепельная корона», этап 5: звук, эффекты, сдача — план

**Цель:** игра звучит и отзывается на действия; README готов к сдаче.

**Спецификация:** `docs/superpowers/specs/2026-10-12-platformer-design.md`, разделы 12, 13, 14, 16.

## Решения этапа

- **События.** `Game` не знает про звук: во время шага он копит список событий
  (`jump`, `attack`, `hit`, `hurt`, `coin`…), после шага отдаёт их слушателю.
  Слушатель — звуковая система. Так логика остаётся проверяемой в Node.
- **Звук** — синтез через Web Audio: осцилляторы с огибающей громкости, файлов нет.
  `AudioContext` создаётся при первом нажатии пользователя. Контекст передаётся
  в систему снаружи, в тестах — подмена.
- **Громкость** — ползунок в главном меню и в паузе, 0 выключает звук;
  значение хранится в профиле.
- **Эффекты:** числа урона (крит — жёлтым и крупнее по смыслу), частицы при гибели
  врага и подборе добычи.
